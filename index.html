Featured Project

Sound Source Localization

Final Year Project

Developed an intelligent sound source localization system aimed at assisting individuals with hearing impairments by identifying the direction of incoming sound sources. The project utilizes microphone arrays, Time Difference of Arrival (TDoA) estimation, signal filtering, and machine learning techniques to improve localization accuracy in noisy environments.

The system is designed for real-time implementation using embedded platforms and focuses on improving spatial awareness in practical environments.
